# ColumbinaHyposeleniaDiscordBotSinging24-7
This project using Python as its main language, and using Discord, random, PyNaCl, Os, and FFMpeg as it's Library. This project allow user to have a Columbina sing her Lullaby song 24/7 since the bot activated by putting Voice ID into VoiceChannel Variable
This project also come with her song to be put inside a folder same as the file
Note: it's recommended to define the path of the song, recommended using "Copy as path" and paste it to MusicLibrary variable
